# Evaluation scope

This HayosoAi evidence package demonstrates a reproducible geometry correction on three original PHerc0800 surface patches. For these inputs, the patch prevents missing-vertex values from contaminating accepted output coordinates during linear and cubic resizing. Coordinates accepted by both versions remain bit-for-bit identical.

The evaluation covers direct use of the exported API, with controlled regressions supplementing the real-scroll inputs. Downstream ink recognition, broader pipeline use, and community adoption remain separate evaluation questions. Maintainer review and competition decisions are external to these measured results.
